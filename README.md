# Cloud-Based Load Management

Java Servlet simulation of workload distribution using the Round Robin scheduling algorithm.

## Features
- Simulated incoming workloads
- Configurable time quantum
- Queue-based Round Robin scheduling
- Execution-order display
- Demonstrates fair resource allocation concepts

## Tech Stack
Java, Jakarta Servlets, Data Structures (Queue), HTML, CSS, Maven

## Important
This is a scheduling simulation, not a deployment on AWS/Azure or another real cloud provider. Understand this distinction before discussing it in an interview.
